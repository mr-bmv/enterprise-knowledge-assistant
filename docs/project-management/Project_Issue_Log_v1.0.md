### Issue-001

При использовании бесплатного Google AI Studio API и стандартной стратегии сегментации Dify документ объемом 16 страниц был разбит на 416 чанков. Это привело к превышению лимитов embedding API (429 RESOURCE_EXHAUSTED). Для разработки принято решение использовать сокращенный Demo-документ и параллельно исследовать оптимизацию стратегии чанкинга.

# Промпт для адаптации документов перед загрузкой в Dify

## Назначение

Универсальный промпт для Gemini, устраняющий два типа проблем чанкинга в RAG:
1. Таблицы, где строка разрывается на несвязанные чанки (значение из одного столбца теряет связь со значением из другого).
2. Списки, смысл которых зависит от вводной фразы-заголовка (например, "Сотрудник обязан:" + пункты списка), при которой пункты списка при разбиении теряют связь с этой фразой.

Принцип один: каждый фрагмент документа должен быть понятен вне контекста остального документа.

## Проверка результата

- **Таблицы:** сверьте цифры/значения в итоговом списке (пункт "в конце") с оригиналом — ни одна цифра не должна "уехать" не в ту строку.
- **Списки:** сверьте количество пунктов в оригинальном списке с количеством сгенерированных предложений — проверка на полноту (LLM иногда пропускает пункт целиком).

## Последовательность работы

- скопировать промпт в выбранный AI (Gemini)
- загрузить необходимый документ
- проверить основную информацию визуально и удалить информацию для проверки (нижние абзацы готового ответа)
- сохранить текст из ответа в документ с расширение `md`
- сформировать название документа из префикса `PP_`+<имя первоначального документа>

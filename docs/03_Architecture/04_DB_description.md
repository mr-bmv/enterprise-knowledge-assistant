### Основные таблицы

**1.** `cars` – автомобили

| Поле | Тип | Описание |
|----|----|----|
| `id` | uuid (PK) | Уникальный идентификатор |
| `number` | text (unique) | Государственный номер (например, «А123ВВ77») |
| `model` | text | Модель авто |
| `city` |    | **Город**, в котором находится машина. Энумератор со значениями из списка `Москва` ,`Санкт-Петербург`, `Уфа` |

**2.** `users` – сотрудники (кто бронирует)

| Поле | Тип | Описание |
|----|----|----|
| `id` | uuid (PK) | Уникальный идентификатор |
| `name` | text | Имя сотрудника |
| `email` | text (unique) | Email для уведомлений (опционально) |

**3.** `bookings` – бронирования

| Поле | Тип | Описание |
|----|----|----|
| `id` | uuid (PK) | Уникальный идентификатор |
| `car_id` | uuid (FK → cars.id) | Какой автомобиль бронируют |
| `user_id` | uuid (FK → users.id) | Кто бронирует |
| `booking_date` | date | **Дата**, на которую бронируется машина (без времени) |
| `status` | text | `'confirmed'` или `'cancelled'` (по умолчанию `'confirmed'`) |

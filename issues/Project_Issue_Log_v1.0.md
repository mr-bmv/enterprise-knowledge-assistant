## ISSUE-001 — Оптимизация размера документа для индексации RAG

Дата: 04.08.2026

Статус: Resolved

### Проблема

При первой попытке загрузки документа `Reglament_Komandirovki_v1.0.pdf`
(16 страниц) в Dify Knowledge Base было создано 416 чанков.

Индексация завершилась ошибкой:

`429 RESOURCE_EXHAUSTED`

Причина:
превышение лимита бесплатного Google AI Studio API при генерации embedding.

### Анализ

Количество чанков оказалось избыточным для демонстрационного сценария.
Первоначальная структура документа была ориентирована на корпоративный регламент,
но не оптимизирована для тестирования RAG.

### Решение

Создана сокращенная версия документа:

`Reglament_Komandirovki_Demo_v1.0.pdf`

После повторной загрузки:

- количество чанков: 78;
- индексация успешно завершена;
- Vector DB успешно заполнена.

### Вывод

Для RAG необходимо учитывать не только объем документа,
но и стратегию разбиения на чанки.

Полная версия документа сохраняется как Enterprise-артефакт.
Demo-версия используется для разработки и тестирования.
